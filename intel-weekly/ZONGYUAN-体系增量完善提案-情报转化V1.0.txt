## 一、情报提炼（对体系真正有用的核心点）

### 1.1 VISTA 提炼（3 个可借鉴点）

| # | 提炼点 | 为什么对我们有用 |
|---|---|---|
| V1 | **无损帧级记忆 + 回看不计操作成本** | 我们的昆仑洞天视觉流水线目前只做"生成→质检→归档"，缺少"生成过程帧级回溯"能力；短剧分镜质检时无法回看中间帧做对比 |
| V2 | **外挂记忆层，不重训基座** | 完全契合我们"轻量化战略"——1.5B小模型+强编排，不需要动基座，只需加检索层 |
| V3 | **多帧对比 + 局部放大读取像素** | 可用于可视化看板巡检（L1巡检时对比前后帧差异）、关键帧一致性校验（同一角色跨帧风格漂移检测） |

### 1.2 WorkBuddy 提炼（3 个可借鉴点）

| # | 提炼点 | 为什么对我们有用 |
|---|---|---|
| W1 | **缓存命中 = 零积分消耗** | 我们已有指纹缓存/增量执行，但缺少"命中率"的量化统计；无法知道哪些任务在重复消耗 |
| W2 | **模型档位积分差距巨大 → 路由优先级** | 我们有免费API优先原则，但缺少算子级的"每次调用消耗多少Token/额度"的细粒度账单 |
| W3 | **自动化/定时任务是缓存控成本核心场景** | 我们的魔搭周报、真值治理、生命周期看板都是定时任务，正是缓存优化的高价值场景 |

## 二、与现有体系对比（Gap 分析）

| 维度 | 现有体系 | 情报启示 | Gap |
|---|---|---|---|
| 视觉记忆 | 全模态真值快照（文本/JSON/指纹），无帧级像素回溯 | VISTA 帧级无损记忆+回看 | **缺帧级视觉快照检索算子** |
| 记忆回看成本 | 真值查询走记忆网关，无"操作步数"概念 | VISTA 回看不计操作成本 | 需明确"记忆检索=零成本"的元规则 |
| 配额管理 | META-RULE-012 三态（正常/预警/只读空转） | WorkBuddy 积分制+缓存命中零消耗 | **缺算子级Token账单+缓存命中率统计** |
| 缓存策略 | 指纹缓存+增量执行+无变更跳过（已实现） | WorkBuddy 高缓存命中=大幅降本 | 已有机制，但**缺可视化看板和命中率指标** |
| 模型路由 | 免费API优先+付费强制人工审批 | WorkBuddy 档位差距大→智能路由 | 已有原则，但**缺每次调用的消耗记录和路由优化反馈** |
| 定时任务优化 | 周报/真值治理/生命周期看板靠指纹比对 | WorkBuddy 定时任务是缓存核心场景 | 机制已有，**缺命中率量化和自动调优** |

**Gap 总结：2 个核心缺口**
1. **视觉帧级快照检索能力**（VISTA 转化）—— 昆仑洞天视觉流水线 + L1巡检
2. **算子级资源账单 + 缓存命中率看板**（WorkBuddy 转化）—— META-RULE-012 完善

## 三、完善方案（可落地增量）

### 3.1 新增 META-RULE-017：视觉帧快照记忆元规则

```
元规则编号: META-RULE-017
名称: 视觉帧快照记忆与零成本回溯元规则
来源: VISTA(MIT何恺明团队)情报转化
核心公理: 记忆检索不计操作成本，只有真实环境操作才消耗资源
```

**规则内容：**
1. 昆仑洞天视觉流水线在生成过程中，自动保存帧级快照（关键帧+中间帧），存入本地持久层 + 魔搭数据湖双备份
2. 帧快照附带四维元数据（空间构图/时序叙事/属性色调/因果世界观），支持按角色/场景/版本检索
3. 回看/对比/放大帧快照属于"记忆检索"，**不计入操作步数、不消耗模型额度**
4. 帧快照用于：分镜质检跨帧对比、角色风格一致性校验、L1巡检可视化看板、短剧成片回溯
5. 帧快照存储遵循"永不删除仅分类备份"铁律，失效帧打 archive 标记
6. 单帧快照 >5MB 时转 WebP 压缩，元数据独立存储

**挂载：** 昆仑洞天视觉资产自治流水线 V1.7 增量项；L1全域巡检可视化增强

### 3.2 新增 META-RULE-018：算子级资源账单与缓存命中率元规则

```
元规则编号: META-RULE-018
名称: 算子级资源账单统计与缓存命中率监控元规则
来源: WorkBuddy(腾讯云)情报转化
核心公理: 缓存命中=零消耗，每次调用必须可计量、可追溯、可优化
```

**规则内容：**
1. 所有外部能力算子（LLM网关/图像生成/API调用）执行时，自动记录：算子ID、模型档位、Token消耗、耗时、是否命中缓存、结果哈希
2. 缓存命中的调用标记 `cache_hit=true`，**Token消耗计为0**，纳入命中率统计
3. 定时任务（魔搭周报/真值治理/生命周期看板）强制启用缓存前置检查，命中率 <60% 时触发告警
4. 模型路由优先级：免费API > 轻量模型 > 高端模型；高端模型调用必须附带"为何不用轻量档"的理由字段
5. 资源账单按日/周聚合，生成算子级消耗排行，支持识别"重复消耗大户"
6. 账单数据写入飞书Base台账 + 魔搭数据湖，纳入L1巡检审计

**挂载：** META-RULE-012 配额稳态保护的增量完善；AxiomGate裁决器增强
